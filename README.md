**Красная Звезда** - независимый русскоязычный проект на базе [Space Station 14](https://github.com/space-wizards/space-station-14).

Проект сочетает классический геймплей SS14 с собственной атмосферой, контентом и визуальным стилем, вдохновлённым СССР и советской научной фантастикой.

В основе Красной Звезды лежит официальный код Space Wizards. Мы стараемся оставаться близко к актуальной версии Space Station 14, чтобы получать новые системы, исправления и технические улучшения напрямую из основной разработки игры.

Хорошие общие изменения, которые подходят не только Красной Звезде, мы также стараемся отправлять обратно в Space Station 14.

При этом Красная Звезда остаётся самостоятельным проектом со своими механиками, балансом, визуальным стилем и подходом к ролевой игре.

## О проекте

Мы не хотим превращать Красную Звезду в сборник механик из десятка разных форков.

Нам важнее аккуратно выбирать действительно интересные идеи, дорабатывать их под современную архитектуру Space Station 14 и писать собственный контент так, чтобы проект оставался понятным и удобным в поддержке.

Мы стараемся:

- использовать актуальную кодовую базу Space Station 14;
- сохранять узнаваемую советскую стилистику;
- аккуратно переносить хорошие идеи из других проектов;
- не усложнять код и игровой процесс без причины;
- развивать собственные механики и контент;
- отправлять полезные общие улучшения обратно в Space Station 14, когда это возможно.

Красная Звезда ориентирована прежде всего на взрослую аудиторию. Мы хотим оставлять игрокам достаточно свободы в ролевом взаимодействии и не вводить искусственные ограничения там, где они не нужны. Конкретные границы определяются правилами игрового сервера.

## Разработка

Основой проекта является официальный репозиторий:

[`space-wizards/space-station-14`](https://github.com/space-wizards/space-station-14)

Если изменение достаточно универсально и может быть полезно основной версии Space Station 14, желательно проектировать его без зависимости от контента Красной Звезды.

Такой код проще поддерживать, а при необходимости его можно подготовить для отправки в Space Wizards.

Подробнее о разработке можно прочитать в [CONTRIBUTING.md](CONTRIBUTING.md).

## Быстрый старт

Склонируйте репозиторий:

```shell
git clone https://github.com/red-star-server/RedStar.git
cd RedStar
```

Инициализируйте движок и подмодули:

```shell
python RUN_THIS.py
```

Соберите проект:

```shell
dotnet build
```

Подробная информация о настройке среды разработки находится в
[официальной документации Space Station 14](https://docs.spacestation14.com/en/general-development/setup.html).

## Лицензирование

Код в репозитории имеет разное происхождение.

Исходный код Space Station 14 сохраняет лицензию **MIT**.

Оригинальные разработки и изменения Красной Звезды распространяются под **AGPL-3.0-or-later**, если явно не указано иное.

Сторонний код сохраняет требования своей исходной лицензии.

Спрайты, звуки и другие ассеты лицензируются отдельно согласно своим metadata и сопутствующим файлам.
